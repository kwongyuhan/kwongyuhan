# Self-Powered Round-the-Clock Spectral Sensing System

An embedded flexible spectral sensing system for in-situ fruit quality monitoring.

This project is based on our research work:

> Self-powered round-the-clock spectral sensing towards in-situ evaluation of fruit quality  
> *Chemical Engineering Journal*, 2025  
> DOI: https://doi.org/10.1016/j.cej.2025.170615

## Overview

Traditional fruit quality detection often relies on destructive laboratory analysis. This project explores a compact and self-powered spectral sensing system that can perform in-situ monitoring and quality prediction.

The system integrates flexible spectral sensing, hybrid energy harvesting, low-power embedded control, wireless data transmission, and machine learning models for real-time fruit quality evaluation.
