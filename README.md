## Research

### Flexible Spectral Sensing Gripper for Real-Time Food Freshness Assessment

**Role:** Co-first author  
**Journal:** *Eng*, 2026  
**DOI:** https://doi.org/10.3390/eng7050243

This work developed a flexible spectral sensing gripper by integrating a 12-channel Vis/NIR spectral sensor array, electronic components, and an ESP32-S microcontroller onto a flexible printed circuit substrate. The system enables conformal multi-point spectral acquisition during potato handling and supports real-time non-destructive quality assessment.

**Keywords:** flexible electronics, spectral sensing, ESP32-S, chemometric modeling, MLR, PLSR, SVM

### Self-Powered Round-the-Clock Spectral Sensing Towards In-Situ Evaluation of Fruit Quality

**Role:** Second author  
**Journal:** *Chemical Engineering Journal*, 2025  
**DOI:** https://doi.org/10.1016/j.cej.2025.170615

This work demonstrates a self-powered flexible spectral sensing device for in-situ fruit quality monitoring. The system integrates hybrid energy harvesting, flexible spectral sensors, a low-power control chip, wireless transmission, and embedded PLSR/SVM models for real-time fruit quality prediction.

**Keywords:** self-powered sensing, flexible electronics, low-power embedded systems, PLSR, SVM, fruit quality monitoring

## Featured Projects

### Self-Powered Spectral Sensing System

An embedded sensing system for round-the-clock fruit quality monitoring.

### Flexible Spectral Sensing Gripper

A gripper-integrated spectral sensing system for real-time food freshness assessment.

- Integrated Vis/NIR spectral sensing units into a flexible gripper interface.
- Built the data collection and modeling pipeline for dry matter content, starch content, and deterioration classification.
- Evaluated preprocessing strategies and machine learning models for robust quality prediction.

**Tech stack:** ESP32-S, FPC, PDMS, spectral sensing, MLR, PLSR, SVM, Python

### STM32 Chess Piece Recognition and Automatic Grasping System

An embedded vision and motion-control project developed for the Beijing Undergraduate Electronic Design Contest.

- Led the team and built the control architecture based on STM32.
- Used RTOS for multi-task scheduling and OpenMV for color classification and coordinate localization.

**Tech stack:** STM32, RTOS, OpenMV, stepper motor control, embedded C
